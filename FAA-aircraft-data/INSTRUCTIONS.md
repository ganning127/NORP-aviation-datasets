# AI Workflow Instructions

This `INSTRUCTIONS.md` file is designed to provide Large Language Models (LLMs) and autonomous coding agents with the necessary context, structure, and execution steps to understand, build, run, and test the data cleaning pipelines in this repository.

## 1. Project Context
This repository contains data cleaning scripts and preliminary analysis for the **SkyQuery** project, which aims to democratize complex aviation datasets. The core workflow involves taking raw, unstructured, or heavily coded aviation data, utilizing LLMs to normalize and clean the data, and outputting structured datasets ready for relational database ingestion (specifically Metabase).

## 2. Repository Structure
The repository is structured around Jupyter Notebooks, with a central PDF serving as the ground-truth data dictionary. 

**FAA Dataset Files:**
* `FAA-aircraft-data/faa_dataset_description.pdf`: The official documentation detailing the internal FAA codes, schemas, and relational logic. **Always reference this document before modifying cleaning logic.**
* `FAA-aircraft-data/acftref-cleaning.ipynb`
* `FAA-aircraft-data/dealer-cleaning.ipynb`
* `FAA-aircraft-data/dereg-cleaning.csv.ipynb`
* `FAA-aircraft-data/docindex-cleaning.ipynb`
* `FAA-aircraft-data/engine-cleaning.ipynb`
* `FAA-aircraft-data/master-cleaning.ipynb`
* `FAA-aircraft-data/reserved-cleaning.ipynb`

## 3. Environment Setup & Dependencies
This is a Python project. The specific packets needed are located in the root folder's `requirements.txt`

## 4. Dataset Gathering
Currently, only cleaning scripts for the FAA Releasable Aircraft Dataset has been added. You can download that dataset here: https://www.faa.gov/licenses_certificates/aircraft_certification/aircraft_registry/releasable_aircraft_download

## 5. Deployment & Integration
The final cleaned datasets generated by this repository are not meant to stay local. 
* **Target Destination:** The cleaned CSV files must be staged for a pull request to the upstream `NORP/norp-data-integration` repository.
